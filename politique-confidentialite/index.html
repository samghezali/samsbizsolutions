Protection de vos données personnelles conformément au RGPD

2. Données collectées

Dans le cadre de notre activité de formation professionnelle, nous collectons les données suivantes :

  • Données d'identification : nom, prénom, fonction, entreprise
  • Coordonnées : adresse email, numéro de téléphone, adresse postale
  • Données professionnelles : poste occupé, besoins en formation
  • Données de connexion : adresse IP (journaux techniques de l'hébergeur)

3. Finalités du traitement

Vos données personnelles sont collectées pour les finalités suivantes :

  • Gestion des demandes de contact et de diagnostic
  • Établissement des devis et conventions de formation
  • Organisation et suivi des formations
  • Facturation et gestion des prises en charge OPCO
  • Envoi d'informations sur nos formations (avec votre consentement)
  • Amélioration de nos services et de notre site web
  • Respect de nos obligations légales et réglementaires

4. Base légale du traitement

Le traitement de vos données repose sur :

  • L'exécution d'un contrat : pour la gestion des formations
  • Le consentement : pour l'envoi de communications commerciales
  • L'intérêt légitime : pour l'amélioration de nos services
  • Les obligations légales : pour la conservation des documents comptables

5. Destinataires des données

Vos données peuvent être transmises à :

  • Votre OPCO (pour les demandes de prise en charge)
  • Notre hébergeur web (GitHub, Inc., via GitHub Pages)
  • Nos outils de gestion (facturation, emailing)
  • Les autorités compétentes (sur demande légale)

Nous ne vendons ni ne louons vos données personnelles à des tiers.

6. Durée de conservation

Vos données sont conservées pendant les durées suivantes :

  • Données clients : 5 ans après la dernière formation
  • Documents comptables : 10 ans (obligation légale)
  • Données de prospection : 3 ans après le dernier contact

7. Vos droits

Conformément au RGPD, vous disposez des droits suivants :

  • Droit d'accès : obtenir une copie de vos données
  • Droit de rectification : corriger des données inexactes
  • Droit à l'effacement : demander la suppression de vos données
  • Droit à la limitation : restreindre le traitement de vos données
  • Droit à la portabilité : récupérer vos données dans un format structuré
  • Droit d'opposition : vous opposer au traitement de vos données
  • Droit de retrait du consentement : à tout moment pour les traitements basés sur le consentement

Pour exercer ces droits, contactez-nous à : sbizsolutions@outlook.fr

Vous pouvez également introduire une réclamation auprès de la CNIL : www.cnil.fr

8. Cookies

Ce site n'utilise aucun cookie de mesure d'audience, de publicité ou de suivi :

  • Aucun cookie n'est déposé sur votre appareil par ce site

Vous pouvez configurer votre navigateur pour refuser les cookies ou être alerté lors de leur utilisation.

9. Sécurité des données

Nous mettons en œuvre des mesures techniques et organisationnelles appropriées pour protéger vos données contre tout accès non autorisé, modification, divulgation ou destruction.

10. Modifications

Cette politique de confidentialité peut être mise à jour. Nous vous informerons de tout changement significatif par email ou via notre site web.
